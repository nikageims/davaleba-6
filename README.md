# 🔢 Counter App - ინტერაქტიული მთვლელი

ეს არის მარტივი და ეფექტური ინტერაქტიული აპლიკაცია, რომელიც შექმნილია JavaScript-ის საბაზისო ფუნქციების (State Management) პრაქტიკისთვის. აპლიკაცია მომხმარებელს საშუალებას აძლევს მართოს რიცხვითი მნიშვნელობები რეალურ დროში.

🌐 **Live Demo:** [singular-gnome-cbcb68.netlify.app](https://singular-gnome-cbcb68.netlify.app/)

## ✨ ფუნქციონალი

- **მატება (➕):** ზრდის მიმდინარე მნიშვნელობას 1-ით.
- **დაკლება (➖):** ამცირებს მიმდინარე მნიშვნელობას 1-ით.
- **გასუფთავება (Reset):** აბრუნებს მთვლელს საწყის პოზიციაზე (0).
- **ინტერაქტიული UI:** ღილაკები და ტექსტი რეაგირებენ მომხმარებლის ქმედებებზე მყისიერად.

## 🛠️ ტექნოლოგიური სტეკი

- **JavaScript (Vanilla):** ლოგიკის სამართავად (DOM Manipulation).
- **HTML5:** სტრუქტურისა და ელემენტებისთვის.
- **CSS3:** ვიზუალური გაფორმებისა და ღილაკების სტილისთვის.
- **Netlify:** პროექტის ჰოსტინგისთვის.
